# Claude Fable 5.1 Build Day — Cape Town

**Date:** 2026-09-12
**Venue:** Roamwork Harrington, 50 Harrington St, District Six, Cape Town, 7925 (2nd floor)
**Site:** https://build.claudecapetowncommunity.com/

A 3.5-hour build sprint on Claude Fable 5.1. Build something, demo it in two minutes, vote on the rest.

## Schedule

| Time  | What |
|-------|------|
| 09:30 | Doors open — coffee and setup |

## Tracks

- **Delight** — something that wasn't possible before. Surprising, beautiful, or fun.
- **Breakthrough** — a novel solution to a problem the previous model couldn't handle.
- **Everyday** — practical automation for a genuine recurring task or annoyance.
